# 三国志9 优化伴侣 · 用户手册

本手册说明「三国志9优化伴侣」每一个可配置项的含义、取值范围与实际效果。所有数值都直接写进正在运行的游戏进程，无需重启游戏；需要重启游戏的改动会在条目里注明。

- 适用版本：2026 版（`San9PK.exe` x86，`San9PKHard` 对应重构）
- 配置文件：与 EXE 同目录的 `San9PKHard*.txt` 与 `San9PKHardSettings.ini`
- 日志：与 EXE 同目录的 `San9Companion.log`

---

## 1. 主窗口

| 控件 | 说明 |
| --- | --- |
| **启动39** | 启动游戏。伴侣先于游戏运行，点击后启动 `San9PK.exe`。 |
| **设置** | 打开设置对话框（见第 2 节）。 |
| 状态栏 | 显示当前连接状态与版本日期。**悬停**可查看完整状态与失败详情。 |

伴侣必须**先**启动再开游戏：连接逻辑靠查找游戏窗口与进程，游戏已经开着的，连接会失败。

## 3. 武将配置页

左侧列表显示 800 名武将（编号 + 姓名）。选中一名武将后，右侧显示其配置。

### 3.1 基本信息

统率、武力、智力、政治四项能力，以及九个兵法系的**当前熟练度**（步兵／骑兵／弓骑／弩兵／水军／攻城／智略／谋略／策略）。这些值从游戏实时读取，作为编辑起点。

下方九个复选框是「可习得最高级别兵法」，勾选表示该武将可以习得对应兵法系。

### 3.2 武将个性化

这是本作弊器相对原版新增的**逐武将**配置，每名武将各一套。

#### 熟练度上限（9 项，每兵法系一个）

| 取值 | 效果 |
| --- | --- |
| 1000 | 游戏原版默认值，熟练度增长到 1000 即停止。 |
| 1–65535 | 该兵法系专用的熟练度上限。 |

熟练度上限越高，兵法威力越大；熟练度到上限后不再增长且不再回落。

#### 熟练度指示图标

熟练度上限输入框右侧有一个状态图标，一眼看出该兵法系当前的配置状态：

| 图标 | 含义 |
| --- | --- |
| （无） | 熟练度上限是默认值 1000（或填 0 表示不修改），且该系没有缩短发动间隔。 |
| ★ | 熟练度上限在 1000 以上、1500 及以下（例如 1200）。 |
| ◎ | 熟练度上限超过 1500（例如 1600、2000）。 |
| ○ | 该兵法系至少有一个兵法的**发动间隔**比游戏原值短。 |

优先级：**○ > ◎ > ★ > 无**。发动间隔被缩短是逐兵法的改动，比上限更能一眼看出配置生效，所以排在最前。

图标随编辑框里的数值实时变化：改动「熟练度上限」或任意一行的「发动间隔(天)」后立刻刷新，不需要先保存。

> **关于图标来源**：原版作弊器（`SanIXPKCheat.exe`）在这一列用的是 8×8 的**复选框**，表示武将对该兵法系的「精通」标志，与熟练度数值无关；两个原始二进制里都没有可以直接复用的图标位图（游戏 `San9PK.exe` 只有 12×10 与 33×11 的光标位图，2019 版工具 `San9PKHard.exe` 没有任何位图资源，原版作弊器的 25 个 BITMAP 与 17 个 ICON 是打包加密的，无法提取）。因此这里的三个字形用宋体的 Unicode 字符直接绘制：★ U+2605、◎ U+25CE、○ U+25CB。**○ 兼作「环」的近似表示**，原版并没有可提取的环形字形。

#### 发动间隔(天)（27 项）

每个可发动的兵法一个间隔值，单位为天：

| 取值 | 效果 |
| --- | --- |
| 0 | 无间隔，每次都可发动。 |
| 1–30 | 该兵法两次发动之间至少间隔的天数（原作上限 15，本作放宽到 30）。 |

游戏原版每个兵法的默认间隔各不相同（例如步兵系多为 9 天、水军系多为 0 天、特殊兵法有 15 天）。填回原值即恢复原状。

把某个兵法的间隔改得比原值短，该兵法系右上角的指示图标就会变成 **○**。

#### 兵法威力系数(%)

| 取值 | 效果 |
| --- | --- |
| 0 | 不修改，沿用游戏原值。 |
| 1–250 | 该武将所有兵法的威力百分比，100 表示 1.0 倍。 |

#### 提升兵法发动机会把握概率

勾选后，该武将发动兵法时**必定发动**，不再受士气、统率、智力等因素影响，也不会出现「明明熟练度很高却被对方抵挡导致没发动」的情况。

> **注意**：本项只影响「能否发动」，不影响「发动后是否被抵挡」。对方武将的抵抗判定始终按原版规则执行，熟练度照常参与。

> **实现说明**：本项作用在游戏内的「发动判定」骰子上（`0x4FEBB0` 函数内的 `0x4FEC5C`），命中时跳过掷骰直接判定成功。抵抗判定（`0x4FEB20` 函数内的 `0x4FEB95`）**完全按原版规则执行**，不会被本项影响。早期的构建把本项错误地挂到了抵抗骰上且强制结果为「抵抗成立」，导致勾选后该武将**必定被抵挡**且熟练度完全不参与判定——这正是「熟练度高的人发动兵法却被熟练度低的人抵挡」的成因。该问题已修复，日志里会打印 `activationBoost: resist roll restored` 一行作为佐证。

#### 兵法威力一定加倍(出动画)

勾选后，该武将的兵法**必定会心**，伤害翻倍并播放会心动画。

### 3.3 亲密度

116 条亲密度记录，用滑块调整，保存到 `San9PKHardPerson.txt`。

### 3.4 保存配置

修改后点**保存配置**写入 `San9PKHardPerson.txt` 与个性化文件；点**确定**关闭对话框。配置保存与写入游戏是两步：先保存文件，再点主窗口的修改流程把配置应用到当前游戏进程。

## 8. 诊断

### 8.1 日志

`San9Companion.log` 与 EXE 同目录，最多 8 MB。记录内容包括：

- 连接、断开、退出、崩溃（含异常码与转储路径）
- 每一次修改事务的开始、每一步写入、结果
- **武将个性化**的每一项应用结果（逐武将一行）
- 失败原因与回滚过程

日志不记录任何与修改无关的高频事件。打开「详细日志」后额外记录每次内存写入的地址与长度。

### 8.2 常见问题

| 现象 | 处理 |
| --- | --- |
| 显示「不支持游戏的当前版本」 | 游戏版本与本伴侣不匹配。需要完全相同的 `San9PK.exe`。 |
| 显示「找不到游戏窗口/进程」 | 伴侣必须先于游戏启动；或游戏未真正进入可修改状态。 |
| 改了但游戏里没反应 | 确认点的是「确认/保存设置」而不是只改了草稿；再打开详细日志看写入记录。 |
| 兵法发动率设了没生效 | 检查是否只保存了配置但没有走「修改」流程把配置推给游戏。 |
| 兵法被抵挡 | 「把握概率」只管发动，不管被抵挡。对方抵抗判定按原版规则执行，熟练度照常参与。 |

### 8.3 崩溃转储

发生崩溃时，Windows Error Reporting 会在 `%LOCALAPPDATA%\CrashDumps` 下生成 `.dmp`。文件名带进程号，伴侣与游戏的转储不会互相覆盖。日志里会打印对应的转储路径。

---

## 9. 卸载

删除 EXE 与 `San9PKHard*.txt`、`San9PKHardSettings.ini` 即可。伴侣只修改运行中的游戏进程内存，不写游戏存档文件；游戏退出后所有修改自动消失。
